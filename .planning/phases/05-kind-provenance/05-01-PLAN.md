<threat_model>
## Threat: `isValidRelPath` 拒绝 `set.json`

**Likelihood:** certain if D-50 is violated.
**Impact:** `saveAsset` throws before any disk I/O, so the asset is never saved.
**Mitigation:** D-50 locks `derived/set.json` as the location; `collectSetAsset` builds the `files` map with `derived/set.json` as the key; `isValidRelPath` accepts it because it matches `/^derived\/[a-z0-9][a-z0-9._-]{0,118}\.[a-z0-9]{1,8}$/`.
**Residual risk:** none — the regex is tested in `app/lib/__tests__/libraryPath.test.ts`.

## Threat: `KIND_KEY` exhaustiveness lost

**Likelihood:** low (would require a refactor to `Partial<Record<…>>`).
**Impact:** adding a new kind without updating `KIND_KEY` would compile, and the panel would show `undefined` for the label.
**Mitigation:** D-41 relies on the `Record` exhaustiveness; if a future refactor changes it, the compile-time guarantee disappears. The plan's gate (`tsc --noEmit`) catches the current shape but not a future `Partial` refactor.
**Residual risk:** low — a `Partial` refactor would be a deliberate decision, not an accident.

## Threat: `collectSetAsset` trusts a malformed `set.json`
